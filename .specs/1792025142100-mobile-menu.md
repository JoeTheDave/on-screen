# Mobile-friendly visualization menu

## Summary

With 22 visualizations the picker overflowed small screens — options ran off the bottom with no
way to reach them. Make the menu fit any viewport. (Same thread also reported a console error on
one of the new visualizations on Joe's Linux machine; awaiting which one + the error text.)

## Iteration plan

### Iteration 1
- `MenuModal.tsx`: panel capped at the dynamic viewport height (`100dvh - 2rem`) and scrolls
  inside itself (overscroll contained); one column on phones, two columns from `sm` up so the
  full list fits on desktop without scrolling; tighter padding on phones.
- Highlight the currently selected visualization (the `currentViz` prop was passed but unused).
